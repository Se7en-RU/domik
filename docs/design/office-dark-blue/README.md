# Кабинет · тёмно-синяя концепция

Фотореалистичная визуальная концепция по геометрии `F1-OFFICE`.

- помещение: 3,440 × 3,095 м с входным уступом, площадь 9,90 м²;
- высота: 3,030 м, плоский матовый натяжной потолок;
- окно: 1,785 × 1,775 м, подоконник около 0,830 м;
- столешница: во всю оконную стену 3,075 м, объединена с подоконником;
- хранение: встроенные шкафы и открытые полки во всю противоположную стену 3,095 м;
- палитра: тёмно-синие стены, графитовые фасады, тёмный дуб, тёплый свет 3000 K.

Изображения — дизайн-концепция, а не рабочие чертежи мебели. Размеры секций, фасадов, вентиляционных решёток и световых профилей требуют деталировки перед изготовлением.
