# Домик — мой дом в 3D

[Открыть 3D-модель](https://se7en-ru.github.io/domik/) · **[Комнаты для ChatGPT и Gemini](docs/ai/README.md)**

## Получить визуализацию комнаты

1. Открой комплект нужной комнаты по ссылке выше.
2. Дай ChatGPT или Gemini ссылку на страницу комнаты и укажи желаемый стиль. Готовый запрос есть на странице.
3. Если ИИ не видит изображения, скачай ZIP, распакуй и приложи **PNG, паспорт и текст запроса** к сообщению.

В каждом комплекте: план с размерами и мебелью, четыре 3D-вида, развёртки стен, паспорт JSON и запрос для ИИ. На GitHub открывай `README.md` комнаты; после публикации [каталог на сайте](https://se7en-ru.github.io/domik/ai/) позволяет просматривать страницы и скачивать комплекты.

**Размеры, окна, двери и расстановку сохранять.** Менять отделку, материалы и свет; переставлять мебель — только по моей просьбе. Потолок и ближние стены скрыты на обзорных видах для удобства: их геометрия есть в паспорте и развёртках. Скосы и часть размеров мебели пока условные. Генерация картинки не гарантирует точности; для строгого совпадения нужно рендерить саму 3D-модель.

## Обновить локально

Node.js 24, затем `npm ci`.

```sh
npm run dev        # просмотрщик: localhost:5173
npm run typecheck
npm test
npm run build      # просмотрщик, GLB/OBJ/JSON и комплекты в dist/ai
npm run export:ai  # обновить комплекты docs/ai для просмотра прямо в GitHub
npm run preview    # готовый сайт: localhost:4173; комплекты: /ai/
```

`dist/house-viewer.html` открывается без интернета. Распакованный комплект комнаты тоже можно открыть через его `index.html`. После изменения модели обновляй комплекты командой `export:ai`; готовые материалы не редактируй вручную. Push в `main` запускает существующую сборку и публикацию Pages. Локальные правки автоматически не отправляются.
